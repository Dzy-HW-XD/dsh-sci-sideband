# Research Future-style LaTeX template

Adapted for DSH Sci Sideband from the public Overleaf template:

- Source: https://www.overleaf.com/latex/templates/research-future-template/dqwvghptfcmj
- Author: Science Partner Journal Program
- License: CC BY 4.0

The report renderer follows this single-column Research Article layout: title,
abstract, keywords, numbered sections, inline figures with captions, and a
single reference list. The generated `.tex` is self-contained and uses standard
LaTeX packages; replace the placeholder figure boxes with local files before
journal submission when a figure is only available as a URL.
