# Scientific writing skill

Write like a research paper, not a summary of papers.

- Start from the research question and the contribution; state why the question matters.
- Separate established evidence from the authors' interpretation and from open hypotheses.
- Use a funnel: problem → gap → approach → evidence → interpretation → limitations → next experiment.
- Every empirical claim must trace to a cited project paper or be labelled as this work's hypothesis.
- Do not inflate novelty. Say what is new relative to the cited work.
- Report limitations and failure modes explicitly; no claim beyond the evidence.
- Use precise, compact paragraphs. Prefer one claim per paragraph.
- Figures must earn their place: each one should answer a question, not decorate.
