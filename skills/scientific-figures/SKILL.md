# Scientific figure skill

For every figure/table provide a plan, not a fabricated plot.

- Define the question the figure answers.
- Choose the encoding: line for trends, bar for comparisons, scatter for relationships, schematic for mechanism/pipeline.
- Specify axes, units, groups, controls, error bars, sample size, and the data source.
- Write a caption that states the takeaway first, then the method/statistics.
- Never invent data points or images; if data is missing, mark it as “data needed”.
- Prefer 2–4 figures; each must be cited in the text and add information.
